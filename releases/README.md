# Release status

This directory is reserved for ZIPs tied to their named, recorded verification results. Historical offline checks are not live-game or multiplayer clearance.

**There is no tested v0.42.8 release ZIP or v0.42.8 release tag.** The current v0.42.8 work is the source draft in [`../extension/`](../extension/). Packaging, installation and live gameplay verification for that draft have not been performed.

Historical ZIPs without a matching tested-release record belong in [`../archive/`](../archive/), where they remain comparison material. Do not promote an archived package to a current release merely because its filename says release, final, or fixed. Use the current source and the [exported context](../exports/) to understand its status.
